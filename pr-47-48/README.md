# Практична робота 47-48

## Windows Forms застосунок обліку поштових відправлень

Предмет Компоненти. Номер у списку 14.

Реалізовано власний клієнт із двох форм: PostingList є головною, PostingEdit — спільним діалогом створення та редагування. Окремий HTTP сервер і проєкт DTO входять до рішення, тому готові попередні роботи для запуску не потрібні. Форми описані C# кодом і відкриваються як проєкт у VS Code.

### Реалізовані функції

PostingList показує таблицю відправлень і кнопки Оновити, Нове відправлення, Редагувати, Видалити. Стовпці містять дані DTO, службові поля сховані. Перед редагуванням і видаленням перевіряється вибір рядка. Видалення має діалог підтвердження.

PostingEdit отримує null для нового запису або вибраний PostingGetDto для редагування. Всі поля заповнюються даними, числові значення вводяться через NumericUpDown, тип доставки обирається зі списку. Вартість відображається лише для читання. Зберегти перевіряє спільні правила DTO, позначає помилки ErrorProvider та викликає POST або PUT. Кнопка тимчасово блокується проти повторного надсилання. Скасувати повертає DialogResult.Cancel без запиту. Після DialogResult.OK список перечитується; за помилки діалог не закривається.

Клієнт звертається лише до REST API, не відкриває SQLite. Відповіді сервера та помилки з’єднання показуються повідомленням. HttpClient належить головній формі, діалог його не знищує.

### Перевірка

Рішення збирається без помилок. Реальний запуск PostingList перевірено через дерево доступності: таблиця містила Іван Коваль → Олена Мельник, Книги, вага 2 кг, цінність 500 грн, вартість 65 грн, і всі чотири кнопки. Захоплення зображення Windows в цьому середовищі повертало тайм-аут, а кліки — помилку геометрії. Тому успішний повний прогін створення й редагування через настільні кнопки не заявлено. Серверні CRUD операції та ті самі правила пройшли інтеграційні перевірки; вебклієнт пройшов фактичний браузерний прогін.

### Сценарій демонстрації

Запустити сервер і клієнт за README. Створити відправлення, перевірити новий рядок; вибрати його, змінити отримувача, зберегти; відкрити редагування й натиснути Скасувати — змін немає. Ввести порожнього відправника та нульову вагу — позначки помилок, запит не надсилається. Видалити запис із підтвердженням, перевірити актуальний список. Без сервера Оновити має показати помилку, а форма залишитися працездатною.

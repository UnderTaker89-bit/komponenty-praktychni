# Практична робота 44

## Графічні макети PostService

Предмет Компоненти. Номер у списку 14.

Підготовлено 21 графічний екран: 7 Windows Forms, 7 веб для широкого екрана, 7 веб для телефона. Файл PostService-mockups.drawio містить редаговані сторінки для diagrams.net; PNG є готовими графічними результатами. Це ескізи, а не HTML реалізація.

## Навігація

Головна → Список або Про програму. Список → Нове, Редагування, Деталі, Підтвердження видалення. Нове й редагування використовують спільну форму; Зберегти повертає до оновленого списку лише після успішної відповіді. Скасувати повертає до списку без збереження. Помилки залишають користувача на формі. Деталі доступні тільки для читання. У підтвердженні Скасувати зберігає запис, Видалити виконує операцію й оновлює список. Із головної сторінки та довідки доступна зворотна навігація.

## Рішення інтерфейсу

Вибраний рядок має синє тло та позначення. Для помилок використано червону рамку, знак ! та пояснення, а не тільки колір. На широкому екрані підказка праворуч, на вузькому — під полем. Таблиця на телефоні замінена картками, кнопки переносяться. Ціна — обчислюване поле; Id і CreatedAt видно в деталях, але сховано в основному списку. Варіанти доставки Standard та Express однакові з контрактом сервера. ПР-47–48 адаптує список як головну форму й використовує одне діалогове вікно створення/редагування згідно з її окремими вимогами.

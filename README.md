# Компоненти Практичні роботи

Предмет **Компоненти**. Номер у списку **14**.

Кожна практична має власну папку, підписаний звіт і окремий коміт. У папках містяться вихідний код, діаграми, макети та результати перевірки відповідно до завдання.

Звіти переглядаються безпосередньо на GitHub. Для C# проєктів потрібен .NET SDK 10; інструкції запуску — у README папок PostServiceSolution. Сервер запускається перед клієнтом. Роботи з однаковим портом 5211 запускайте по черзі.

ПР-42, 43, 47–48 і 48–50 містять самодостатній сервер, оскільки початковий сервер попередніх робіт не був наданий. Власні правила й тариф описані явно. Код Windows Forms збирається, запуск і завантаження списку перевірені; повний інтерактивний прогін кнопок обмежений технічною недоступністю керування вікнами. API та вебклієнт пройшли інтеграційні перевірки. Для ПР-30–31 зафіксовано фактичні результати браузерного тестування коду викладача.

## Межі перевірки

Windows Forms дійсно запускається та показує дані сервера; це підтверджено через доступність вікна. Повний автоматизований прогін кліків настільного клієнта недоступний: захоплення Windows повертає timeout, а натискання — coordinate input geometry is unavailable. Сценарії демонстрації наведено у звітах. Для ПР-30–31 виконано аналіз коду й автоматизоване браузерне відтворення, а не заявлений ручний сеанс. Для ПР-28 сформовано тестову документацію, результати відсутнього застосунку не вигадані.

Під час початкової збірки NuGet не зміг завантажити базу вразливостей (NU1900). Наявних локальних пакетів вистачило для збірки; це попередження не є результатом перевірки вразливостей. У контрольних збірках вимкнено лише мережевий аудит NuGet на час команди, налаштування проєктів та системи не змінювались.

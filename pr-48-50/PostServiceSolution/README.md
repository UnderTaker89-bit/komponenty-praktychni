# PostService Практична 48-50

Відкрити цю папку у VS Code. Потрібен .NET SDK 10 і відновлення NuGet пакетів.

1. `dotnet restore PostService.slnx`
2. `dotnet build PostService.slnx`
3. У першому терміналі `dotnet run --project PostService` — сервер http://localhost:5211.
4. У другому терміналі `dotnet run --project PostService.Web` і відкрити http://localhost:5222.

База postings-ef.db створюється автоматично. Різні роботи запускайте по черзі: порт сервера один.
HTTP приклади містять демонстраційні записи; ідентифікатор у PUT і DELETE замініть на отриманий при POST.

## Контракт і правила

Спільний проєкт PostService.Dtos визначає JSON контракт, валідацію та тариф. ПІБ відправника й отримувача обов’язкові, до 128 символів; вміст до 500; тип доставки Standard або Express; вага 0.001–1000 кг; габарити 0.1–1000 см; цінність 0–1000000 грн. Ціна лише для читання: (40 + 10 × вага) × коефіцієнт доставки + 1% цінності; Express має коефіцієнт 1.5. Це правила цієї самодостатньої реалізації, оскільки вихідний сервер попередніх робіт не наданий.

API: GET /postings, GET /postings/{id}, POST /postings, PUT /postings/{id}, DELETE /postings/{id}. Валідація повертає 400 з errors, відсутній запис — 404, створення — 201, зміна та видалення — 204. Клієнти не звертаються до БД напряму.

# Практична робота 48-50

## Вебзастосунок обліку поштових відправлень

Предмет Компоненти. Номер у списку 14.

Результат — власний вебклієнт PostService.Web на ASP.NET Core та окремий PostService REST API. Код демонстраційного репозиторію не копіювався. Структура екранів і термінологія відповідають макетам ПР-44.

### Реалізація

Головна має переходи до списку й розділу Про програму. Список підтримує створення, вибір рядка або картки, редагування, деталі, оновлення й видалення. Спільна форма new/edit змінює заголовок і HTTP метод, але повторно використовує розмітку полів та перевірки. Деталі лише для читання. Скасувати повертає до списку без запиту на збереження. Видалення відбувається після модального підтвердження; його скасування не змінює дані.

Браузер звертається до /api/postings вебклієнта. ASP.NET проксі HttpClient пересилає запити до PostService на 5211 і повертає його JSON та статуси. Дані зберігає сервер, не localStorage. Проксі дає спільне походження без додаткових CORS налаштувань. Серверна адреса налаштовується ключем PostServiceUrl; недоступність сервера повертає 503 і зрозуміле повідомлення.

Порожні та невалідні поля мають рамку, знак !, пояснення й aria-invalid. Помилки з сервера також прив’язуються до полів. Всі значення з даних екрануються перед вставленням у HTML. На широкому екрані список — таблиця; до 650 px — картки. Поля на телефоні одноколонкові, помилки під ними, навігація переноситься.

### Фактична перевірка

Виконано браузерний сценарій: перехід із головної до списку; порожня форма і підказки; створення; вибір та редагування; перегляд деталей; адаптація до 430 px; скасування видалення; підтвердження видалення; повідомлення після зупинки сервера. Усі перевірки пройдено, неперехоплених JavaScript помилок немає. Сервер пройшов позитивні й негативні REST сценарії та перезапуск зі збереженням SQLite. Зображення web-desktop.png і web-mobile.png показують фактичний застосунок.

### Запуск

Відкрити PostServiceSolution у VS Code, виконати dotnet build PostService.slnx. У першому терміналі dotnet run --project PostService. У другому — dotnet run --project PostService.Web. Відкрити http://localhost:5222. Сервер і клієнт запускаються як окремі процеси. Контракт визначено у PostingDtos.cs.

Вихідний код розміщено в цьому Git репозиторії. bin, obj і бази виключено через .gitignore.
